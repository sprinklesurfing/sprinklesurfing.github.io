# Teaching website

This is a small Jekyll site for GitHub Pages. The public pages are `index.md`, `bio.md`, `research.md`, and `teaching.md`. The shared layout is in `_layouts/default.html`, and styles are in `assets/site.css`.

Professional details on the Bio, Research, and Teaching pages are drawn from the locally supplied `Wesley_CV.docx`. The CV file itself, personal contact details, and teaching source material are not published. Directed Reading Program student names and project titles appear on the Teaching page at the site owner's request.

The old `/cv/` address forwards to Research. When updating page content or navigation, bump `site_version` in `_config.yml` so links request the current pages instead of a saved browser copy.
