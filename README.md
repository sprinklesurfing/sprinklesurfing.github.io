# Teaching website

This is a small Jekyll site for GitHub Pages. The public pages are `index.md`, `bio.md`, `cv.md`, and `teaching.md`. Edit their placeholder text when content is ready. The shared layout is in `_layouts/default.html`, and styles are in `assets/site.css`.

The site is intentionally free of personal contact details, CV files, and teaching source material until those items are explicitly chosen for publication.
